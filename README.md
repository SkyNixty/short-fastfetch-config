## Install script

Use this if you don’t want to do it manually:

```bash
mkdir -p ~/.config/fastfetch \
&& curl -L -o ~/.config/fastfetch/config.jsonc \
https://raw.githubusercontent.com/SkyNixty/short-fastfetch-config/main/config.jsonc
```
